## 维护规则

- 文件名为 `NNNN-<topic>.md`，ID 为 `ADR-NNNN`。
- 待定方案使用 `proposed`；授权明确且取舍已确定后使用 `accepted`。
- 不采用的方案可标记 `rejected`；被新决策替代时标记 `superseded`；不再推荐但暂无替代时标记 `deprecated`。
- 替代时新建记录，更新双方关系及索引，保留旧决策正文。
- 关联任务和规范只填写实际存在的文档；没有时写 `none`，不为了填模板创建额外文档。
