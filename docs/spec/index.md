# 项目规范

这里只记录项目实际存在、未来实现需要持续遵守的约束。不要复制通用开发常识，也不要根据模板猜测技术栈或测试命令。

## 规范入口

当前尚无项目特有规范。根据真实代码与已接受决策，按模块或领域创建文档并登记：

| 领域 | 规范文档 | 适用范围 |
| --- | --- | --- |

每份规范按需说明契约、不变量、边界和可执行的质量检查。检查命令必须有项目依据；暂不可运行时明确原因。

## 维护方式

- Agent 按影响范围从本索引读取，不要求全量加载。
- ADR 负责解释选择的原因；规范保留当前有效的约束并链接相关 ADR。
- 实现改变了约束时同步修正文档。没有新约束时不增加文件。
- 任务特有的步骤和未完成事项留在任务记录，不写成永久规范。
